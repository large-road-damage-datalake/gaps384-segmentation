# GAPs384

## Overview

GAPs384 is a task-specific segmentation package derived from the pavement-crack-detection project.

- Task: segmentation
- Images: 404
- Annotations: 3010
- Classes: 1 (crack)
- Annotation format: paired PNG masks

This local raw copy contains 384 valid image-mask pairs under the provided folder.
